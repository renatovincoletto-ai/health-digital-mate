# Health Brand Studio

quero criar um sistema para médicos e dentistas, para que eles possam fazer ter um site próprio publicado pelo sistema, atualizar as informações com um assistente igual a este do lovable, fazer a gestão da agenda de forma automatizada com integrações com gmail e outlook, um sistema para que eles possam subir as informações da marca e que o sistema gere peças automaticamente para serem publicadas nas redes sociais, uma integração com um agende que possa fazer a criação dos conteúdos e programar de forma automática nas redes indexadas, criação e gestão de campanhas de google ads e mídias sociais integradas. além desses tópicos você pode me sugerir quais outros seriam legais ter dentro desses sistema. a ideia é criar uma agência digital para o setor da saúde de forma automatizada, sem gestão de pessoas, apenas agendas e os usuários
